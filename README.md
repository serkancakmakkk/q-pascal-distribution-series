# q-Pascal distribution series: numerical examples

Code for the paper

Y. Aydın, S. Çakmak, S. Yalçın, "Applications of q-Pascal Distribution Series
to Certain Subclasses of Analytic Functions", Bulletin of the Karaganda University.
Mathematics Series.

The notebook `qpascal_numerics.ipynb` computes Table 1 and draws Figures 1–3 of the paper.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/serkancakmakkk/q-pascal-distribution-series/blob/main/qpascal_numerics.ipynb)

## How to run
Click the "Open in Colab" button and choose *Runtime → Run all*.
The notebook needs only `numpy`, `matplotlib` and `pandas`.

## Files
- `qpascal_numerics.ipynb`: the code
- `table1.csv`: Table 1 of the paper
- `fig1.pdf`, `fig2.pdf`, `fig3.pdf`: Figures 1–3 of the paper
